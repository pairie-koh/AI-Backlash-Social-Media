If you're Vibe Coding, if you're using AI to build an application, then one of the most important steps you can take in the process is evaluating the AI-generated code. Now let me stop for a minute. It is very difficult, even for someone with years and years of software development experience, it is very difficult to evaluate code that has been written by someone else. But it's something that's necessary for any software project, especially if it's AI-generated code. And now I know that many of you do not know software development. You don't know code, You don't know Python, you don't know JavaScript or TypeScript, you don't know Rust, whatever your application is built in, and that's fine. There are still three simple questions that you can ask and get answers to that will help you evaluate the AI-generated code. First, ask the question, do I understand what this is doing? If you don't understand, ask the AI to explain it to you. If necessary, go line by line. The second question is this, does it match existing patterns? Once you start evaluating the code, you're going to understand some of the patterns in your application. Make sure new code matches those patterns. And then finally, the third question is this. What happens with bad inputs? You see, AI is very good at handling the good path, the happy path. But what about bad inputs? What about wrong inputs? Make sure the code matches that too. Answer these three questions and you've started along the road of evaluating the AI generated code. I've written an article about this as part of my Engineering for Vibe Coder series.
