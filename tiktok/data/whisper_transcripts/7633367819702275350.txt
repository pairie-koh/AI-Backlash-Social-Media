We just rebuilt our entire studio website in four hours using AI. Here are the exact workflow, tools, and skills we used. Step one, the design system. We took our brand identity from Figma and uploaded it into Cloud Design. The AI created a complete design system for us with spacing, shadows, components, everything. But Cloud Design doesn't give you a lot of credits yet. So we downloaded the design system and dropped it into Cloud Code running on Opus 4.7. Step two, build the site. First, we brainstormed the site architecture together, optimized for conversions, aligned with our company values and offers. Then we installed the Taste Skill to make sure the site doesn't look like every other AI-generated website. We also created custom assets and dropped them in. Then we let Claude build the site using all the context we provided. And from there, we just refined until it looked perfect. Step 3, Animated Launch. We installed Remotion Skill to add custom animations which make the site way more premium. Once everything was dialed in, we pushed it to Vercel and the site was live.
