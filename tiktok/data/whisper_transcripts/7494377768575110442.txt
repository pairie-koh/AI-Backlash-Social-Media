Is it worth learning to code in 2025? AI can already do all of the jobs that we as humans do. It's the first technology that has no limit. The people who were writing software, they're gone. Back in 2019, it was sufficient for you to go to university, learn Python, Java, do a couple of projects, and boom, you were given a six-figure job offer upon graduation. Internships were offered like candy, and the bar to get in was just so much easier than before. Now in 2025, AI has significantly altered the landscape of tech and coding. Salesforce CEO, Mark Benioff recently announced that the company won't be hiring any additional software engineers this year, since they've seen a 30% productivity boost from their AI tool Agent Force. And now I know what you're thinking. It seems really scary. There's so many AI tools out there. Is it actually worth learning to code in 2025? And my answer, 100 million percent yes. But there is a huge caveat. Every time a new technology comes around, it feels like the world is ending for some people and it kind of does because if you don't adapt there is no career for you but if you do adapt you don't just survive you thrive. The same thing is happening with AI and coding. You need to have a high value skill. You need to be advanced and you need to learn how to code with AI and if you don't learn AI you will be replaced by someone who does. Start by mastering the basics of coding with beginner-friendly languages like Python or JavaScript. Platforms like Coditech or FreeCodeCamp to learn are excellent but the goal is mainly project-based learning. Do not get stuck in tutorial hell. Step two, AI integration. Once you get a little decent at coding, the next step is to level up and start using AI to become a faster, more efficient coder. For me, the first AI tool that I used was Copilot when I was doing a software engineering project in which I had to develop a Pomodoro application. I would create a function header and then I would write comments like fill out this function for me and it would do it right away. If you don't know specifically where you even want to start out with Copilot, just ask ChatGPT. I'm not even joking. Learn AI through AI.
