You guys want to know how I use AI in my content? I use AI when I want to generate captions where I don't want to type out every single caption so I use AI to do it for me. When I think of a YouTube title and I type it out myself and I'm thinking hmm is there a way to make this title more captivating and I just wanted to brainstorm other possible options of a good title to use that's how I use AI. Or when I need to type out SEO tags for YouTube description and I don't want to type out every single tag every time I make a video I use AI to generate the words for me. Notice how I'm still using my original ideas and content, but using AI as a tool just to simplify the process of what I'm doing. I'm not using AI to generate a script for me to say on a video that I want to talk about. I'm not using AI to fully generate my thumbnails. I'm not using AI to make fake videos and fake images so that I can use it as a filler for my content. I think that's the real issue that people have with AI. Not because AI can be a very good tool for convenience on certain situations. because essentially AI is pulling out the originality, the creativity, the integrity, the effort that the content creator is supposed to generate on their end. So in my opinion, guys, if you are a content creator and 90% of yourself is AI generated, really go back to the drawing board, learn how to edit, learn how to draw original thought, original creativity, because that is the art of content creation.
