Sáng thứ bảy của một kỹ sư hệ thống kiêm AI Agent Builder sẽ như thế nào? Nghỉ ngơi à? Không. Tôi dành thời gian để ngồi chỉ đạo AI làm việc thay mình. Khởi động nhẹ nhàng bằng việc xử lý 4 projects cùng lúc qua CLI với 2M Cloud Code và 2M Quen Code. Để tối lưu tốc độ, bật YOLO Mode cho Quen và Auto Mode cho Cloud. Tư duy ở đây là chuẩn bị file plan cực kỳ chi tiết từ trước. Gõ lệnh xong là cấp full quyền cho AI tự execute. không ngồi approve lắt nhắt. Tiếp theo, check hệ thống Vive Code hàng nhà tự trồng. Đây là tool tôi build để quản lý các cron job tự động. Ví dụ xét lịch chạy lệnh shell để pull code từ open source của Codex về xem có cái gì mới không. Demo luôn. Hẹn một phút sau tự động pull vào folder chỉ định. Chạy mượt. Hệ thống này tôi thích hợp 4 con CLI coding top đầu hiện nay. Cloud, Gemini, Codex và Quen để backup khi chán dùng CLI. Tiện thay, tôi set up luôn một M-Job tự động phân tích thị trường chứng khoán, ném prompt vào mô đồ tương ứng để nó tự cào data macro trả về file báo cáo MacDown cực nét. Sắp tới, tôi sẽ tích hợp thêm text-to-speech, sáng dậy pha cà phê là có AI đọc báo cáo thị trường luôn. Đã làm hệ thống thì tính di động phải cao, lười ngồi PC thì mở mobile app tôi tự xây dựng rồi kết nối thẳng với server.
