Esta automatización que ves aquí funciona y la creé en menos de un minuto. De hecho, yo no toqué ni un solo nodo, sino que Cloud lo hizo todo por mí. Literalmente, solo le escribí lo que quería crear y al rato me devolvió un enlace que llevaba directamente a mi flujo dentro de N8n. Y ahora seguramente te estés preguntando cómo se hace. Vamos paso a paso. Primero, entra a la web de Cloud, descarga la aplicación de escritorio e inicia sesión de forma normal. Después, instala Node.js, ya que es lo que permite que Cloud pueda comunicarse con el servidor MCP y ejecutar tus automatizaciones. Luego, abre el repositorio de Neo8n para MCP en GitHub, copia el primer comando que aparece y pígalo en tu terminal. Con eso, el servidor ya queda corriendo y listo para usarse. Ahora, abre Cloud Desktop, ve al apartado de configuraciones, entra a la sección para desarrolladores y dale al botón que dice editar configuración. Ahí dentro, pega el bloque de código del repositorio que aparece justo debajo del comando que acabas de ejecutar. Simplemente hacen falta completar dos campos, la URL de tu instancia de Neo8n y tu clave API. La URL la puedes copiar desde la barra de navegación de N8n cogiendo únicamente el dominio. Y la clave API puedes generarla directamente desde el apartado de configuraciones en la sección de API Keys. Una vez pegados los datos, guarda, cierra Cloud y vuelve a abrirlo. Ahora ya verás el conector N8n-MCP con todas las herramientas disponibles en el panel. Desde aquí ya puedes pedir a Cloud que construya automatizaciones enteras a partir de una simple instrucción en lenguaje natural. Pero ahora viene la mala noticia. Y es que para que todo esto funcione, lo más importante es el prompt. Sin él, el modelo no sabrá cómo crear los flujos correctamente y no servirá de nada.
