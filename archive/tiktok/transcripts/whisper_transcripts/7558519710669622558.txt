Watch this AI agent I built for HR recruiters. It helps them manage job applications automatically. I created it using BotPress and Make.com. Here's how it works. It all starts with an autonomous node. That's what allows the agent to make decisions and perform the right actions. Then I added a prompt that guides it to collect the applicant's job position, full name, email, and resume. The agent can also answer general questions using the company's knowledge base. When it answers, it follows a specific tone and guidance to keep everything consistent and professional. Once the applicant finishes the form, the agent creates a personalized confirmation email that will be sent automatically later. After that, I added a search knowledge card. This gives the agent access to information like open job positions, HR policies, and company details. When all the application data is ready, the agent sends it to a sub-workflow called Send Application Data. That sub-workflow makes an API call to make.com and sends all the collected information. In make.com, the data arrives through a webhook. Then, an HTTP module downloads the resume file, uploads it to a Google Drive folder, and saves all the applicant's details, like their full name, email, and Google Drive link, into Google Sheets. At the same time, the applicant receives a personalized confirmation email, created by the AI agent on Botpress, and the HR recruiter gets a message with all the applicant's details. Everything runs smoothly and automatically. Applicants get instant confirmation, and recruiters have all the data neatly organized in one place.
