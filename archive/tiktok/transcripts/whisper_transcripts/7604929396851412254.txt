AI image generators are notoriously bad at generating text, and here's why. AI image generators use a process called diffusion, which is where they start with pure noise and then reduce it step by step. It is essentially just guessing which pixels should be dark versus light based on patterns it's seen for those objects before. This is really great for things like faces or trees where imperfections don't really matter, so a face that looks slightly off still looks like a face, but for text it's a lot more unforgiving. So for example, the difference between an O and a Q is just a single line. Or the letters RN right next to each other look a lot like an M, depending on the font that you're using. So that's why the letters that the image models generate often look like text-shaped gibberish instead of actual characters from the alphabet. So essentially these image models are really good at visual style, but not so much at linguistic interpretation because that's not what their technical architecture is built for.
