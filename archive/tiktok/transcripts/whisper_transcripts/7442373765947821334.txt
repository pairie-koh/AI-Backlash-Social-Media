Cursor just released a new update and it's pretty insane. It lets you have an agent inside of cursor that writes the code for you. Here are the three most impressive features. One, it runs terminal commands in the past. When you use the composer in cursor, you would have to run terminal commands manually, for example, to install a specific package. But now with agent, the terminal commands can be run directly inside of the agent to picking its own context with composer. You often had to direct the AI to pick the right context. You had to either tag the entire code base or you could include files manually, but agent now does this automatically and can pick the most relevant context by itself. Three executes more jobs with one prompt. The agent is more, well, agent-like you can give it a larger task and it should be able to break it down into smaller tasks and execute them all until it's done. At least that's the theory for now.
