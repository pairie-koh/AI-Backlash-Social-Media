How to see properly when you're using cursor. Using cursor, the screen can feel pretty congested when you're using the AI pane. It's like you're paying for the AI by not being able to fully see your code. It's hard to read the AI pane because it's kind of small, but I recently found out you can fix this. In the AI pane, select Open Chat as Editor. Then right-click that new tab and select Move into New Window. Now you can read the AI pane without struggling and you get to see your code in full screen.
